Configuration

Nimbus reads nimbus.config.ts from your project root. Every option has a sensible default.

import { defineConfig } from "nimbus";

export default defineConfig({
  region: "icn1",
  build: { command: "npm run build", output: "dist" },
});
Tip: run nimbus config check to validate your file before deploying. Learn more
OptionTypeDefault
regionstring"iad1"
build.commandstring"npm run build"
build.outputstring"dist"
